# Sri Lanka Heritage

**Tourism & Cultural Website — English**

---

## 🌍 About The Project

This website provides comprehensive information about Sri Lanka's **traditions, culture, festivals, cuisine, and 25 special tourist destinations** — all in English.

Perfect for:
- 🧳 Tourists planning a trip to Sri Lanka
- 🎓 Students and researchers learning about Sri Lankan culture
- 🌏 Anyone curious about the Pearl of the Indian Ocean

## ✨ Features

- ✅ **Fully Responsive** — mobile, tablet, desktop
- ✅ **Mobile Hamburger Menu** — smooth slide-in navigation
- ✅ **Scroll Animations** — cards fade in as you scroll
- ✅ **Back to Top Button** — appears after scrolling down
- ✅ **Contact Form** — with validation & simulated submission
