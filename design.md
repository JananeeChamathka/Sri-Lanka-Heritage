# Sri Lanka Heritage - Design System

## Color Theme

### Primary Colors
- **Primary**: `#1565C0` - Main blue used for buttons, badges, and key UI elements
- **Primary Dark**: `#0D47A1` - Used for hover states and darker accents
- **Primary Light**: `#42A5F5` - Used for subtitles, hover highlights, and lighter accents

### Secondary Colors
- **Secondary**: `#0d1b2a` - Dark navy used for headings and section backgrounds
- **Dark**: `#0a1929` - Used for footer background and hero overlay
- **Light**: `#f0f4f8` - Used for section backgrounds

### Neutral Colors
- **White**: `#ffffff` - Primary background color
- **Gray**: `#6c757d` - Used for text and subtle elements
- **Gray Light**: `#e2e8f0` - Used for borders and subtle backgrounds

### Accent Colors
- **Accent**: `#00bcd4` - Teal accent color (reserved for specific use cases)

## Design Patterns

### Color Applications by Section
1. **Header/Navigation**: Dark background (`rgba(15, 15, 26, 0.95)`) with primary blue accents
2. **Hero Section**: Dark overlay with glassmorphism effect, primary light for subtitles
3. **Introduction**: Light blue gradient background (`#e3f2fd` to `#bbdefb`)
4. **Traditions**: White background with primary blue icons and accents
5. **Festivals**: Dark gradient background with glassmorphism cards
6. **Tourist Places**: Light gray background (`#f0f4f8`) with white cards
7. **Food Section**: White background with light blue gradient cards
8. **Contact Section**: Dark gradient background with glassmorphism effect
9. **Footer**: Very dark background (`#0a0a15`) with primary light accents

### Interactive Elements
- **Buttons**: Primary blue gradient background with white text
- **Cards**: White background with subtle shadows and hover effects
- **Links**: Primary blue color with hover transitions
- **Badges**: Primary blue background with white text

### Effects and Animations
- **Glassmorphism**: Used in hero content, festival cards, and contact form
- **Hover Effects**: Card lift, scale, and shadow transitions
- **Scroll Animations**: Fade-in effects for sections
- **Transitions**: Smooth 0.3s ease transitions throughout

## Typography
- **Primary Font**: Poppins (sans-serif)
- **Secondary Font**: Noto Sans Sinhala (for Sinhala text)
- **Heading Colors**: Secondary (`#0d1b2a`) for main headings, white for dark backgrounds
- **Text Colors**: Gray (`#6c757d`) for body text, white for dark backgrounds

## Spacing and Layout
- **Container Max Width**: 1200px
- **Section Padding**: 80px vertical
- **Card Padding**: 25-30px
- **Border Radius**: 12px (cards), 8px (buttons, inputs)
- **Shadows**: Subtle (`0 4px 20px rgba(0, 0, 0, 0.1)`) and large (`0 10px 40px rgba(0, 0, 0, 0.15)`)

## Responsive Design
- **Breakpoints**: 
  - 1024px (tablet landscape)
  - 768px (tablet portrait)
  - 480px (mobile)
- **Grid System**: CSS Grid with responsive columns (3 → 2 → 1)

## Color Theme Summary
The website uses a cohesive blue-based color scheme with:
- **Primary Blue**: For main interactive elements
- **Dark Navy**: For backgrounds and depth
- **Light Grays/Blues**: For contrast and readability
- **White**: For clean, modern appearance
- **Glassmorphism Effects**: For modern UI elements
